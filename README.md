# Сервис планирования ремонта квартиры

## Назначение
Веб-приложение для помощи пользователям в планировании и организации ремонтных работ в квартире. Сервис позволяет создавать сметы, отслеживать этапы ремонта, управлять списком материалов и контролировать бюджет.

## Целевая аудитория
- Владельцы квартир, планирующие ремонт
- Частные мастера и бригады ремонтников
- Дизайнеры интерьеров
- Люди, желающие контролировать расходы на ремонт

## Предметная область
Система автоматизации процесса планирования ремонтных работ, включающая расчет необходимых материалов, составление смет, планирование этапов работ и контроль выполнения задач в рамках выделенного бюджета.

## Основные сущности
- **Помещение** - комната или зона квартиры (гостиная, кухня, спальная, ванная и т.д.)
- **Вид работ** - тип ремонтных операций (поклейка обоев, укладка плитки, покраска, монтаж пола и т.д.)
- **Материал** - строительный материал с характеристиками (название, единица измерения, цена)
- **Смета** - расчет стоимости работ и материалов для конкретного помещения
- **Этап ремонта** - последовательность выполнения работ с датами начала и окончания

## Основные функции
- Расчет площади помещений и необходимого количества материалов
- Формирование сметы ремонта с учетом стоимости работ и материалов
- Проверка доступности материалов на складе и расчет общей стоимости
- Планирование последовательности этапов ремонта
- Контроль бюджета и фактических расходов
- Генерация списка покупок строительных материалов

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных для хранения информации о помещениях, материалах и сметах;
- реализация системы пользователей с регистрацией и авторизацией;
- разработка REST API для мобильного приложения;
- контейнеризация приложения в Docker;
- настройка CI/CD для автоматического тестирования и развертывания.
